# Olá Brasil — پرتغالی برای ما

اپلیکیشن آموزش **پرتغالی برزیلی برای فارسی‌زبانان**، با تمرکز ویژه بر زندگی روزمره در برزیل و آمادگیِ زبانیِ فرایند شهروندی (naturalização).

یک **PWA موبایل‌محور، آفلاین‌محور و چندزبانه (فارسی/پرتغالی/انگلیسی)** با پشتیبانی کامل RTL/LTR.

> A Brazilian-Portuguese-for-Persian-speakers learning app: offline-first,
> mobile-first PWA with a flagship Brazilian-citizenship track.

---

## Quick start

```bash
cd app
npm install
npm run dev          # open the printed localhost URL
```

اپ بدون هیچ کلید API کار می‌کند: دستیار هوش مصنوعی در حالت آفلاین (Mock) و صدا با Web Speech مرورگر.

## Scripts

| Command                | کار |
| ---------------------- | --- |
| `npm run dev`          | سرور توسعه (Vite + HMR) |
| `npm run build`        | بیلد تولید (`tsc -b && vite build`) در `dist/` |
| `npm run preview`      | سرو نسخهٔ بیلدشده |
| `npm run typecheck`    | بررسی نوع‌ها |
| `npm run lint`         | ESLint + Prettier |
| `npm run lint:fix`     | اصلاح خودکار |
| `npm test`             | تست‌های واحد/یکپارچه (Vitest) |
| `npm run coverage`     | تست + پوشش |
| `npm run e2e`          | تست End-to-End (Playwright) |
| `npm run seed:validate`| اعتبارسنجی محتوای اولیه (Zod + یکپارچگی) |

> اجرای iOS/Android: این نسخه یک PWA است و روی مرورگر موبایل «Add to Home Screen»
> می‌شود. مسیر مهاجرت به React Native در `../ARCHITECTURE.md` مستند شده است.

## قابلیت‌ها

- **Onboarding**: انتخاب زبان/نام/هدف/زمان + **تعیین سطح واقعی چندمهارتی** → برنامهٔ شخصی و سطح CEFR.
- **داشبورد**: برنامهٔ امروز، streak، ادامهٔ آخرین درس، دسترسی سریع.
- **مسیر آموزشی**: درس‌ها با هدف، واژگان، جملات، مکالمه، نکتهٔ گرامری، آزمون، و صوت (TTS pt-BR).
- **فلش‌کارت + مرور هوشمند**: الگوریتم **FSRS** با Again/Hard/Good/Easy، دِک‌های موضوعی و «اشتباهات من».
- **ماژول شهروندی**: معرفی شخصی، سؤالات مصاحبه با پاسخ نمونهٔ سطح‌بندی‌شده، **شبیه‌ساز مصاحبه** (با امتیاز اکتشافی و بدون ادعای قبولی/رد)، جملات اداری، **چک‌لیست مدارک**، تاریخ/جامعه/فرهنگ، **شهر من**، و **منابع** با تاریخ بررسی و برچسب «اطلاعات عمومی، نه مشاورهٔ حقوقی».
- **تلفظ**: پخش عادی/آهسته، ضبط و بازپخش، نکات ویژهٔ فارسی‌زبانان، جفت‌های کمینه.
- **گفت‌وگو با دستیار**: چند نقش، اصلاح ملایم، تبدیل اشتباه به فلش‌کارت.
- **پیشرفت/آمار، تنظیمات (تم روشن/تاریک، اندازهٔ متن، سرعت گفتار، Provider)، پروفایل‌های خانوادگی، Export/Delete داده.**
